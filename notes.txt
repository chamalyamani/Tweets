"First, we prepared the dataset and created 18 different preprocessing versions. Then we transformed the tweets into numerical vectors using Count BOW, Binary BOW and TF-IDF.
For the similarity part, we used cosine similarity to find the top-10 most similar tweet pairs for each preprocessing dataset.
For sentiment classification, we split the data into 80% training and 20% test data using stratification. We trained Logistic Regression, Linear SVM and Multinomial Naive Bayes models on the different datasets and vectorizations.
We used GridSearchCV with 5-fold cross-validation to find the best hyperparameters. Finally, we evaluated the models using accuracy, AUC, precision, recall and F1-score, and compared their performances.
Our best configuration was Logistic Regression with D1 and Binary BOW, achieving about 90.9% accuracy and 0.979 AUC."



Pourquoi utilise-t-on cosine similarity ?
→ Pour mesurer la similarité entre deux tweets vectorisés.

Quelle est la différence entre cosine similarity et classification ?
→ Similarité = comparer deux tweets ; classification = prédire leur sentiment.

Pourquoi séparer train et test ?
→ Pour évaluer le modèle sur des données qu'il n'a pas vues pendant l'apprentissage.

Pourquoi GridSearchCV ?
→ Pour chercher automatiquement les meilleurs hyperparamètres.

Qu'est-ce que l'accuracy ?
→ Proportion de prédictions correctes.

Pourquoi utiliser F1-score ?
→ Pour équilibrer precision et recall et regarder les performances par classe.

Qu'est-ce que l'AUC ?
→ Une mesure de la capacité du modèle à distinguer/séparer les classes à partir de ses scores.

Quel est notre meilleur modèle ?
→ Logistic Regression + D1 + Binary BOW, accuracy ≈ 0.909, AUC ≈ 0.979.
